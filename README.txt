When the PDF is finished:
1. Put the PDF inside the "comics" folder.
2. Open index.html.
3. Find the button:
   <button class="disabled" disabled>PDF COMING SOON</button>
4. Replace it with:
   <a class="primary" href="comics/your-file.pdf" target="_blank">READ PDF</a>

For a new comic, duplicate the comic-feature block in index.html and change the title, cover image, description and PDF path.

The website is static, so you can publish it on a static hosting service without a database.
